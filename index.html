Firebase Setup

Realtime Database Security Rules

To allow your ESP32 microcontroller to push sensor telemetry and this dashboard to stream it in real time, set your Firebase database rules to public test mode:

  1. In your Firebase Console, click the Rules tab (shown in your screenshot next to Data).
  2. Replace the rules editor with the JSON snippet below:
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
  1. Click the blue Publish button at the top right of the Rules tab.
  2. Once published, click the "🚀 Push Test Data" button on the dashboard to test instant live synchronization!
